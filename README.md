# 마음 장부

축의금·부의금을 봉투별로 기록하고, 마감할 때 장부 합계와 실제 현금을 대조하는 오프라인 장부입니다. HTML 파일 하나를 브라우저에서 열면 됩니다.

**[장부 내려받기](https://github.com/ParkJoonHyeok/maeum-ledger/raw/refs/heads/main/index.html)**

## 접수부터 마감까지

1. 내려받은 `index.html`을 열고 행사 이름과 날짜를 입력합니다.
2. 화면에 표시된 번호를 봉투에 적고, 이름과 금액을 입력한 뒤 **접수 저장**을 누릅니다. 키보드에서는 `Enter`로 다음 칸에 이동하고 `Ctrl+Enter`로 저장합니다.
3. 마감할 때 **실제 현금 대조**를 열고 권종별 수량을 입력합니다. 계좌 이체를 함께 기록했다면 현금과 장부 합계에 그만큼 차이가 납니다.

접수 내역은 봉투 번호나 이름으로 찾아 수정할 수 있습니다. 전체 명단은 CSV로 내보내고, 검색한 내역만 골라 인쇄할 수 있습니다.

## 보관과 이동

자동 저장 기록은 사용한 브라우저에 남습니다. **다른 PC로 옮길 때는 ‘기록 포함 HTML 저장’으로 새 파일을 내려받으세요.** JSON 백업은 **백업 복원**으로 다시 불러올 수 있습니다. 기록이 담긴 HTML·JSON·CSV에는 이름과 금액이 들어 있으므로 개인 보관용으로 관리하세요.

## 개발

앱 코드는 `index.html`에 있습니다. Node.js 환경에서 `npm test`로 접수·복원·현금 대조 등의 동작을 확인할 수 있습니다.

## 변경 이력

- 사용 안내와 접수·백업·복원 회귀 테스트 추가
- 봉투별 경조금 접수와 현금 대조를 지원하는 오프라인 장부 공개
