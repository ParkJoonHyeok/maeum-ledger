# 마음 장부

인터넷 없이 HTML 파일 하나로 사용하는 경조사 접수 장부입니다. 축의금·부의금 접수부터 마감 시 현금 대조까지 지원합니다.

## 시작하기

1. `index.html`을 내려받아 Chrome 또는 Edge에서 엽니다.
2. 행사 이름·구분·날짜를 입력합니다.
3. 봉투 번호, 이름, 금액을 입력하고 **접수 저장**을 누릅니다.
4. 봉투에도 화면과 같은 번호를 적어 두면 대조하기 편합니다.
5. 마감하거나 다른 기기로 옮기기 전에 **기록 포함 HTML 저장**을 누릅니다.

GitHub에서 내려받을 때는 파일 목록의 `index.html`을 선택하고 **Download raw file**로 저장하세요. GitHub의 코드 보기 화면에서는 실행되지 않습니다.

## 주요 기능

- 이름·금액·관계·메모 기록, 수정·삭제
- 삭제 후에도 유지되는 봉투 번호, 중복 봉투 번호 차단
- 동명이인과 100만원 이상 금액의 확인 절차
- Enter 다음 칸, Ctrl+Enter 저장, Esc 취소
- 검색, 정렬, 전체 내역 CSV 내보내기, 현재 내역 인쇄
- 최근 30개 변경의 작업 취소
- 실제 지폐·동전 수량으로 현금 대조
- 브라우저 자동 저장 및 다른 창의 변경 충돌 감지
- 기록 포함 HTML 저장, JSON 백업·복원, 이전 버전 백업 읽기

## 저장 방식

자동 저장은 현재 브라우저의 `localStorage`에 보관됩니다. 원본 HTML 파일 자체는 변경되지 않습니다. 브라우저 데이터 삭제, 개인 정보 보호 모드, 파일 경로·브라우저 변경에 따라 자동 저장 기록에 접근하지 못할 수 있습니다.

**다른 기기로 가져갈 때는 ‘기록 포함 HTML 저장’으로 새로 내려받은 파일을 사용하세요.** 다운로드가 완료됐는지 확인하고 중요한 기록은 별도 백업도 보관하세요. HTML·JSON·CSV에 포함된 이름과 금액은 암호화되지 않습니다. 실제 접수 기록이 들어 있는 파일은 저장소에 커밋하지 마세요.

동시 사용은 한 창에서 하는 것이 좋습니다. 다른 창의 변경을 감지하면 저장을 멈추고 최신 기록을 불러오도록 안내합니다. 실시간 공동 편집이나 기기 간 동기화 기능은 없습니다.

현금 대조는 장부 전체 금액과 비교합니다. 계좌 이체 등이 포함돼 있다면 그 금액을 고려해 대조하세요. 작업 취소 이력은 현재 실행 중인 창에만 남습니다.

## 개발 및 검증

설치나 빌드 없이 `index.html`을 수정하면 됩니다. 외부 라이브러리·CDN·서버를 사용하지 않습니다.

Node.js가 설치돼 있다면 다음 명령으로 동작 검증을 실행할 수 있습니다.

```sh
npm test
```

검증 항목: 입력·수정·삭제·취소, 봉투 번호 유지, 중복 차단, 검색 합계, 다시 열기, HTML 데이터 왕복, 여러 창의 저장 충돌, 현금 대조, 이전 백업 호환, 브라우저 저장 실패, 행사 분리, 잘못된 백업 거부, CSV 수식 문자 처리.

테스트는 모의 DOM으로 애플리케이션 코드를 실행합니다. 실제 브라우저의 화면 배치·다운로드·인쇄 동작은 별도 확인이 필요합니다.
